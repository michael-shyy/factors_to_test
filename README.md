# factors_to_test

本仓库用于存放**尚未经过测试**或**测试效果较差、待日后改进**的因子。

## 用途说明

- 存放新开发但尚未完成回测验证的因子
- 存放已测试但表现不佳、需要进一步优化的因子
- 作为因子研究的暂存区，待改进后再迁移至正式因子库

## 目录结构建议

```
factors_to_test/
├── untested/       # 未经测试的新因子
└── underperforming/  # 测试效果差、待改进的因子
```

## 注意事项

- 本仓库中的因子**不建议直接用于实盘**
- 每个因子文件建议在文件头部注明当前状态（未测试 / 测试中 / 待改进）及简要说明
- 改进完成并通过测试后，请将因子迁移至正式因子库
